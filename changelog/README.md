# Changelog

One markdown file per change set, named `YYYY-MM-DD-slug.md`, newest date
last when the directory is listed. A change set is a coherent piece of work,
usually one push, not one commit: several commits that ship one thing get one
entry.

Write the entry as part of the work, not afterwards from memory. Say what
changed and why it changed; a reader six months from now has the diff already
and needs the reasoning. Note anything a successor has to do by hand (a cache
to clear, a credential to rotate, content still to fill in).

The same rules as the rest of the repo apply here: no em dashes, and no
invented detail.
