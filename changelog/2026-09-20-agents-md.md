# The rules move to AGENTS.md, and catch up with the code

`CLAUDE.md` had drifted about a week behind the site. It documented six routes
where there are ten, named seven of the twenty-five design tokens, and said
nothing about the overview deck, the TIAP page, `PageHeader.astro`, video
covers, or the two build scripts. Three of its statements were not just stale
but wrong, which is worse: an agent acts on them.

- `AGENTS.md` is now the rules, under the name most tools look for.
  `CLAUDE.md` is a short pointer to it. One document to keep current.
- **The no-JavaScript rule is rewritten around what it protects**, which is
  that every route renders and reads with scripting off. As written before, the
  only exception was the demos under `public/`, which made `/slides/aims-lab`
  a violation: it is an Astro page with a `<script>`. The deck's present mode
  and motion are optional enhancements on a page that already scrolls and
  reads, and they are bundled at build time, so the rule now names them and
  states that condition. Nothing in the code changed.
- The claim that the header shares `--content-wide` with the homepage and
  footer is gone. It uses `--header-width`, deliberately.
- Every token is listed with what it is for, including `--gold`, `--charcoal`,
  `--on-charcoal`, `--usm-band`, `--header-width`, the six `--area-*` figure
  hues, and the two fonts.
- New sections: page chrome (the band, the header, `PageHeader.astro` and its
  `width` prop), the overview deck (sheets, `--px` scaling, `deck:qr`,
  `deck:pptx`), and video covers (the `-thumb` cut, padding rather than
  cropping, why a webm is not automatically worth shipping).
- The file map, the route list, and the Commands block match the repo again.
  `deck:qr` and `deck:pptx` were missing from Commands.
- Deployment gains the hosting limits the site is measured against, and why
  there is no CDN in front of Pages.

Deleted `src/data/people_old.ts`. It was tracked, imported by nothing, and a
second roster to mistake for the real one.

Still to do by hand: `/projects` passes `description="..."` to `Base`, so its
meta description and Open Graph description are three literal dots. It needs a
sentence under 160 characters.
