# AIMS website

The rules for this repo live in [`AGENTS.md`](AGENTS.md): the non-negotiables
(no em dashes, no client-side JavaScript on site pages, everything visual
through the design tokens), the file map, the content rules for each data file,
the deck and demo pipelines, and how it deploys.

Read it before editing anything here. It is one document on purpose, so keep it
current rather than adding a second one: if you change how something works,
change the paragraph that describes it in the same commit.

The parent `research/CLAUDE.md` adds the conventions shared with the rest of
the research directory (paper figures, Weights & Biases).
